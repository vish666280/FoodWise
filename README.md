# FoodWise - Household Food Waste Reduction Website

## Project topic
Study food-waste practices among households and design an intervention using digital tools for:
- Meal planning
- Expiry tracking
- Surplus food sharing
- Responsible disposal
- Food-waste awareness and measurement

## Included features
1. Responsive landing page
2. Household impact dashboard
3. Food saved / waste / meals / sharing statistics
4. Weekly meal planner
5. Expiry tracker with urgency labels
6. Surplus food community board
7. Food-waste logging
8. Learning / awareness cards
9. Eco-score concept
10. Light / dark mode
11. LocalStorage persistence
12. Mobile responsive navigation
13. Functional modal forms
14. No backend required for demo

## How to run
Simply open `index.html` in Chrome/Edge/Firefox.

For VS Code:
1. Open the FoodWise folder.
2. Open `index.html`.
3. Use Live Server if installed.

## Important
This is a front-end academic project/demo. The surplus-sharing feature is intentionally a demo board. For a real deployment, connect it to verified food-distribution organisations, user authentication, moderation, location/privacy controls and food-safety workflows.
